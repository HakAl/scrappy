Add pluggable embedding model support. BGE-small remains the default, but users can now install higher-quality models via `pip install scrappy[nomic]` (768-dim Nomic Embed) or `pip install scrappy[jina]` (768-dim Jina Code). The system auto-detects the best available model, or users can explicitly configure via `SEMANTIC_INDEX_EMBEDDING_MODEL` environment variable. Each model uses its own separate LanceDB index to avoid dimension conflicts.
